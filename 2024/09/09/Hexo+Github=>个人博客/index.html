Hexo + GitHub 搭建个人博客

前言

本文记录使用 Hexo + GitHub Pages 从零搭建个人博客的完整流程，分为四步：本地环境准备 → 连接 GitHub 仓库 → 本地生成博客 → 部署上线。

一、本地环境准备

1. 安装 Node.js

前往官网下载：<https://nodejs.org/zh-cn>

2. 安装 Git

前往官网下载：<https://git-scm.com/downloads>

3. 安装 Hexo

二、连接 GitHub 仓库

1. 创建仓库

在 GitHub 上新建仓库，注意以下几点：

  • 仓库名必须为 用户名.github.io（例如 76-s.github.io）
  • 勾选 Public
  • 勾选 Add a README file
  • 点击 Create repository 完成创建

2. 配置 SSH Keys

在任意文件夹空白处右键，选择 Git Bash Here，输入：

连按 4 次 Enter 使用默认配置即可。然后：

  1. 进入 C:\Users\用户名\.ssh 目录
  2. 用记事本打开 id_rsa.pub，全选并复制其中的内容
  3. 打开 GitHub → Settings → SSH and GPG keys → New SSH key
  4. 名称随意填写，将复制的内容粘贴到 Key 一栏，保存

在 Git Bash 中测试连接是否成功：

首次连接会提示确认，输入 yes 回车。看到 Hi 用户名! You've successfully authenticated 即表示配置成功。
